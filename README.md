# 🏥 Hospital Management System

A **ASP.NET Core Web API-based Hospital Management System** built using **Clean Architecture** principles.  
It manages hospital operations like patients, doctors, appointments, and billing in a structured and scalable way.

---

## 🚀 Features

- Patient Management (CRUD operations)
- Doctor Management
- Appointment Scheduling
- Billing Module
- DTO-based architecture
- AutoMapper integration
- FluentValidation for input validation
- Repository Pattern (Generic Repository)
- Clean Architecture (Layered Structure)

---

## 🛠️ Tech Stack

- ASP.NET Core Web API (.NET 8)
- Entity Framework Core
- SQL Server
- AutoMapper
- FluentValidation
- Dependency Injection

---

## 📁 Project Structure

- **Application Layer** → DTOs, Interfaces, Services, Validators  
- **Infrastructure Layer** → Database, Repository Implementation  
- **Web API Layer** → Controllers & API Endpoints  
- **Domain Layer** → Core Entities

---

## 🎯 Purpose

This project demonstrates backend development skills using modern design patterns and clean architecture principles for scalable enterprise applications.
